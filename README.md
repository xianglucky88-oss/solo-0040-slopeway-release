# 坡径通行编译台

把有向步道拓扑、现场量测和封闭通告编译为可回放的通行发布件。复核人员可以查询指定时点的轮椅或步行路线、查看方向级证据、比较两个版本，并将验过的发布件交给外业或公开渠道。

## 本地运行

需要 Python 3.11 或更新版本。服务使用 Python 标准库和内置 SQLite，页面使用原生 HTML、CSS 和 JavaScript ES Modules。Node.js 用于构建时的语法检查。

在仓库根目录启动服务：

```bash
python3 -m slopeway
```

在另一个终端装载苇汀片区样例，然后访问 `http://127.0.0.1:8765`：

```bash
python3 -m tools.demo
```

启动参数 `--db` 可指定独立数据库，`--port` 可更换端口，`--verbose` 可输出请求日志。端口改变时用 `python3 -m tools.demo --url http://127.0.0.1:新端口` 装载数据。默认数据库为 `var/slopeway.sqlite3`。每个数据库装载一次示例。

## 复核一条路线

在「通行图」选择公开渠道对应的最新苇汀发布件，按 UTC 时间和「手动轮椅」查看，从栖岸换乘厅（`arch`）到汀步花园（`garden`）。

| UTC 查询时点 | 预期距离 | 证据 |
| --- | ---: | --- |
| 2026-09-18 08:00:00 | 410 m | 观景段正向开放 |
| 2026-09-18 09:20:00 | 480 m | 观景段正向封闭，走浅湾路亭一侧 |
| 2026-09-18 10:00:00 | 410 m | 通告在结束边界失效 |

切到截点较早的发布件，同一天 09:20 的路线为 410 m。该发布件编译时尚未收到封闭通告。街段方向可在选择器或路线分段中打开，查看所用量测、较低优先级的记录和有效通告。

「证据入库」接收 `examples/` 中的拓扑或证据批次 JSON。「编译与发布」可以选择已登记的拓扑修订和服务窗，比较通行结论，复核或下载发布件，推进或恢复渠道头。数据接口和实体契约见 [项目规格](PROJECT_SPEC.md)。

## 核验

```bash
python3 -B -m tools.build
python3 -B -m tools.workflows all
```

构建检查 Python、浏览器模块、SQLite DDL 和 API 路由导入。工作流核验在临时数据库中通过回环 HTTP 调用生产 API，并覆盖采集、查询、封存及渠道交接。可把 `all` 换成 `topology`、`survey`、`notice`、`compile`、`directions`、`route`、`coverage`、`compare`、`verify`、`publish` 或 `restore`。正式自动化测试套件留待后续。
